# 排版参数

## 字体与间距

| 参数 | 建议值 |
| --- | --- |
| 正文字号 | 15px |
| 正文行高 | 1.9 |
| 正文颜色 | #333333 |
| 次要文字 | 13px 到 14px，#555 或 #888 |
| 标题字号 | 19px 到 23px |
| 段落间距 | margin: 12px 0 |
| 章节间距 | margin-top: 28px 到 32px |
| 卡片内边距 | padding: 14px 16px |
| 卡片圆角 | border-radius: 6px 到 8px |
