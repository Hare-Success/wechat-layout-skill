Fenno Image

Use Fenno's OpenAI-compatible image generation endpoint to create raster images with gpt-image-2.

Part 1

Quick Start

1.Read the user's requested prompt, style, aspect ratio, size, and output location.

2.Require the API key in FENNO_API_KEY. If it is missing, ask the user to set it or provide permission to set it for the current shell session.

3.Run the bundled script:

bash


python <skill-dir>/scripts/generate_image.py --prompt "..." --output-dir outputs

4.Inspect the saved image before returning it when visual quality matters.

5.In the final response, provide the generated file path and mention any important generation settings.

Part 2

Defaults

•Base URL: https://api.fenno.ai

•Endpoint: /v1/images/generations

•Model: gpt-image-2

•Environment variable: FENNO_API_KEY

•Default size: 1024x1024

•Default output format: PNG

Do not hardcode API keys into skill files, scripts, logs, or final responses. Prefer environment variables.

Part 3

Script Usage

bash


python <skill-dir>/scripts/generate_image.py \\

&#x20; --prompt "A clean product render of a glass tea cup on a walnut table" \\

&#x20; --size 1024x1024 \\

&#x20; --output-dir outputs \\

&#x20; --filename tea-cup.png

Useful options:

•--prompt: required image prompt.

•--size: image size such as 1024x1024, 1536x1024, or any size supported by the endpoint.

•--n: number of images to request.

•--quality: optional quality value, passed through when provided.

•--style: optional style value, passed through when provided.

•--output-dir: directory for generated image files.

•--filename: filename for a single image. For multiple images, the script appends an index.

•--base-url: override the base URL only if the user explicitly asks.

Part 4

Prompting Guidance

Write prompts as direct visual briefs. Include subject, scene, composition, lighting, material, camera or art style, and constraints. Keep file-format or delivery instructions outside the prompt unless they are visual requirements.

When the user asks for variants, generate --n images when appropriate. When the user asks for a specific aspect ratio, choose the closest supported --size and state that choice.
